# 红利打新底仓计算器 · 红利指数看板

六大红利指数今天贵不贵、该建多少底仓、下一步买还是卖，都在一个只在自己家里跑的面板里算清楚。

[English](./README.en.md)

## 这是什么

一个单机运行的个人红利底仓管理工具。它把「看估值 → 定计划 → 手机上照着下单 → 回来记账核对」串成一条闭环，但**只做计划、记录和核对，不会自动下单，也不替你决定买什么**。

数据来自公开行情与官方指数资料；行情按腾讯 → 东方财富 → 本地缓存三级兜底，取不到时明确显示 NA，不编数字。

## 能做什么

- **六大红利指数看板**：指数点位、股息率、估值分位与近十年序列；旁边是沪深 300 / 中证 500 / 中证 1000 的市场环境。数据缺口显示 NA 而不是猜测。
- **官方成分与权重**：缓存指数的官方成分股与权重，作为选股参考。
- **底仓测算**：按 10 万 / 20 万等资金规模，算出各标的的建议股数（A 股按 100 股整手）。
- **建仓 / 追加 / 再平衡 / 清仓计划**：生成可冻结的挂单计划，冻结后不会被行情刷新改掉。
- **手机辅助下单**：把计划整理成手机上可照着操作的清单，成交后回到面板登记。
- **真实持仓与策略现金台账**：记录成交价、数量与现金变动，区分策略资金与外部资金。
- **未完成批次恢复**：下单中断后可继续未完成批次，不用重头再来。
- **Excel 导出**：把当前计划与持仓导出为表格，便于自行核对。
- **Docker 自托管**：数据落本机 SQLite，备份目录只读挂载。

## 怎么跑起来

### Docker（推荐）

```bash
# 两个宿主目录必须预先存在，未设置会直接报错而不是静默创建
APP_DATA_DIR=/path/to/data \
APP_BACKUP_DIR=/path/to/backups \
PUBLIC_APP_URL=http://127.0.0.1:8771 \
docker compose up -d --build
open http://127.0.0.1:8771/
```

### 本地直接运行

```bash
python3 server.py --port 8771     # 只用标准库，无需额外依赖
```

首次使用请先按 `docs/pm/PRODUCT_PLAN_V1.0.md` 的「首次启动」走一遍，确认数据目录、项目标识与备份路径。

## 数据与隐私

- 持仓、计划、成交记录只存本机 SQLite；不连接券商、不上传账户信息。
- 仓库内 `dev.db` 仅为开发样例；真实数据目录与备份目录不得提交。
- 行情与指数资料来自公开接口，接口失效时显示 NA，不影响已有记录。

## 已知限制

- 不自动交易、不接券商接口；成交需要你自己在券商 App 完成并回填。
- 部分指数的合法同口径历史序列缺失，面板显示 NA；这是数据现实，不是缺陷。
- 首版不含费用、公司行动、部分成交与撤单建模。
